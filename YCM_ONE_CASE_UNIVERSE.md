# YCM ONE — Case Universe

Scope: India + International

The canonical YCM ONE case taxonomy contains 35 master domains. These domains are intended to be shared across Public Platform, Customer + Family 360, Universal Assistance, Service + Opportunity Intelligence, Execution Engine, CRM, Business Network, Field/Offline, Finance, CRI and Management reporting.

## Case lifecycle

Customer/Family → Case → Domain → Sub-service → Assignment → Documents → Consent → Payment → Application/Execution → TAT → Outcome → CRI/CSAT.

Professional/licensed areas must route to appropriately authorized professionals/providers where required.
